### 1. Download the official Rocky GenericCloud image directly onto Proxmox. Rocky currently publishes a Rocky 10.2 GenericCloud QCOW2 image for x86_64.

- Create a directory:
mkdir -p /var/lib/vz/template/qcow2
cd /var/lib/vz/template/qcow2

- Download image:
wget https://download.rockylinux.org/pub/rocky/10.2/images/x86_64/Rocky-10-GenericCloud-Base.latest.x86_64.qcow2

- Verify:
ls -lh


### 2. Create an empty Proxmox VM that will become the template.

qm create 9000 \
  --name rocky-10-cloud-template \
  --memory 2048 \
  --cores 2 \
  --cpu x86-64-v3 \
  --net0 virtio,bridge=vmbr0 \
  --scsihw virtio-scsi-pci \
  --ostype l26


VM 9000 has CPU 2, RAM 2GB, NIC vmbr0, Disk none


Note : Do not start it yet



### 3. Import the Rocky QCOW2 disk into local-lvm

- qm importdisk imports an external disk image into a Proxmox VM, and QCOW2 is supported by Proxmox's disk-import workflow.

qm importdisk \
  9000 \
  /var/lib/vz/template/qcow2/Rocky-10-GenericCloud-Base.latest.x86_64.qcow2 \
  local-lvm

- verify

qm config 9000

unused0: local-lvm:vm-9000-disk-0

### 4. Attach that imported disk as the main boot disk

-- run
qm set 9000 --scsi0 local-lvm:vm-9000-disk-0

- check verify 

qm config 9000

### 5. Add the Cloud-Init drive.

- run
qm set 9000 --ide2 local-lvm:cloudinit
- result

update VM 9000: -ide2 local-lvm:cloudinit
  Logical volume "vm-9000-cloudinit" created.
  Logical volume pve/vm-9000-cloudinit changed.
ide2: successfully created disk 'local-lvm:vm-9000-cloudinit,media=cdrom'
generating cloud-init ISO


### 6. Configure the boot disk and serial console.

qm set 9000 --boot order=scsi0

update VM 9000: -boot order=scsi0

qm set 9000 --serial0 socket --vga std

update VM 9000: -serial0 socket -vga serial0


- verify again

qm config 9000

boot: order=scsi0
cores: 2
cpu: x86-64-v2-AES
ide2: local-lvm:vm-9000-cloudinit,media=cdrom
memory: 2048

vmgenid: 84a4805c-9f8f-4e86-941f-85abc54bc159


### 7. Convert VM 9000 into a Proxmox template.

qm template 9000

Renamed "vm-9000-disk-0" to "base-9000-disk-0" in volume group "pve"
  Logical volume pve/base-9000-disk-0 changed.

### 8. Final

you can use the template in the terraform by using the template id not cloud id or iso image anymore.
